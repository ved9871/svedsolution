# SVED Solution — Off-Page SEO / Backlink Submission Plan

**Purpose:** prioritised list of directories, listing sites and profiles to build backlinks *and* the off-site citation consensus that gets svedsolution.com named by AI (ChatGPT, Perplexity, Gemini). For an AI-visibility agency, the sites AI models actually trust (Clutch, G2, Crunchbase, LinkedIn, Trustpilot) do double duty: SEO backlinks **and** GEO/entity signals.

> **DA/DR caveat:** figures are approximate, well-known industry values as a planning guide — **not live**. Verify with Ahrefs (DR) / Moz (DA) before client reporting. Authorize the Ahrefs connector or top up DataForSEO to pull live numbers.
> **NAP:** use one identical Name/Address/Phone everywhere (see `offpage-submission-data.md`). Inconsistent NAP hurts both local SEO and AI entity resolution.

Priority key: **P1** = do first (high authority + agency-relevant + AI-citation value) · **P2** = solid authority / regional · **P3** = batch-produce, lower DA fillers.

## Suggested rollout (off-page cadence)

- **Week 1 (foundation):** LinkedIn (company + Ved), Google Business Profile, Bing Places, Apple Business Connect, Crunchbase, Trustpilot — the identity/entity core AI reads first.
- **Week 2 (agency authority):** Clutch, G2, GoodFirms, DesignRush, Sortlist, The Manifest, UpCity, TechBehemoths, Bark.
- **Week 3 (regional):** India — Justdial, IndiaMART, Sulekha, TradeIndia, StartupIndia. UK — Yell, FreeIndex, Cylex UK, Europages.
- **Week 4 (content/profile + software):** Medium, Quora, Reddit, GitHub, Slideshare, Behance, About.me, Product Hunt, Wellfound, F6S, Capterra/GetApp/TrustRadius.
- **Ongoing:** one P3 batch (5–10 sites) per week.

## Rules for every submission
1. **Identical NAP** and the same 250-char description everywhere (consistency = the AI-entity signal).
2. Use the canonical URL `https://svedsolution.com/` and link relevant service pages where allowed.
3. Prefer categories: *SEO Agency / Digital Marketing / AI / Software Services*.
4. Add the same logo, socials and Ved Prakash as founder/contact.
5. Log every submission + live profile URL in `offpage-backlink-tracker.csv`.
