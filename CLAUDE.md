# svedsolution.com

Static site for **SVED Solution**, an AI visibility and 360° SEO agency.
Live at https://svedsolution.com. Repo: `ved9871/svedsolution`.

Generated by a Python script, deployed on Cloudflare Pages, with the audit
tool, forms and CMS auth running as Pages Functions.

---

## Commands

```bash
pip install -r requirements.txt
python build.py                                  # generates dist/
python -m http.server 8787 --directory dist      # preview at :8787
python tools/build_fonts.py                      # only if fonts change
python tools/make_logo.py                        # logo + favicon PNGs
python tools/make_social.py                      # social profile/cover images
```

Every push to `main` deploys automatically. **Never edit `dist/`** — it is
generated and gitignored.

Cloudflare Pages build settings:
- Build command: `pip install -r requirements.txt && python build.py`
- Output directory: `dist`

## Layout

```
build.py              ALL page content and the generator. Single source of truth.
assets/               style.css, app.js, fonts/, favicons, og-image
content/blog/*.md     blog posts (front matter + markdown), edited via /admin/
functions/api/        audit.js, contact.js, leads.js, auth.js, callback.js
admin/                Decap CMS (index.html) + leads dashboard (leads.html)
static/               copied to site root: robots.txt, llms.txt, _headers, _redirects
tools/                asset generators
brand/                logo pack, social kit, brand-messaging.md
dist/                 build output — generated, gitignored
```

Page content lives in `build.py` as data structures, not templates:
`PAGES` (14 core pages), `SERVICES` (17), `INDUSTRIES` (10), `TEAM`,
`AI_PLATFORMS`, `SEO_TOOLS`, `CERTIFICATIONS`, `TERMS_SECTIONS`,
`PRIVACY_SECTIONS`. Add an entry to the list and the page generates itself.

## Hard-won gotchas — read before changing these

**Asset caching.** `_headers` pins `/assets/*.*.css` and `/assets/*.*.js` as
`immutable`. That is only safe because `build.py` content-hashes those
filenames (`style.<sha>.css`). An earlier version pinned the unhashed name and
**every CSS change was invisible in production for days.** Do not add
`immutable` to a stable filename.

**Canonicals are verified at build time.** `verify_canonicals()` fails the
build if any page's canonical points at a URL that was not written. It caught
the GEO page declaring `/services/generative-engine-optimization/` while living
at `/generative-engine-optimization/` — a canonical aimed at a 404 silently
deindexes the page. Keep the `slug` in `PAGES` matching where `build()` writes.

**CSS escapes take one backslash.** `content:'\2715'`, never `'\\2715'`. A
doubled backslash printed the literal text `\2715` on all ten industry pages.

**Never `.lower()` a label.** Use `lc()`, which preserves acronyms (IVF, IT,
SaaS, D2C, Web3, EdTech) and trailing punctuation. A blanket lowercase rendered
"IVF" as "ivf" and "Web3, Crypto" as "web3 crypto".

**`_redirects` rejects absolute URLs.** Cloudflare Pages only accepts relative
paths. www→apex must be a dashboard Redirect Rule, not a `_redirects` line.

**Audit input must be `type="text"`.** `type="url"` makes the browser reject
`example.com` before the request is sent. `candidateUrls()` in `audit.js`
resolves https/http × apex/www × path/origin and audits the first that responds.

**Fonts are self-hosted.** Loading them from fonts.googleapis.com was most of a
4.0s mobile FCP. If you change a face, re-run `tools/build_fonts.py`; the
`@font-face` block is at the top of `style.css`.

**Pages occasionally drops one asset.** `poppins-700.woff2` 404'd in production
while four siblings served, with git sizes matching exactly. Any new commit
forces a re-upload.

**PowerShell here is 5.1.** No `&&` — use `;`. Long commit messages via a
variable, not a heredoc. (The Pages build runner is Linux, so `&&` in the build
command is correct.)

## Env vars and bindings (Cloudflare Pages → Settings)

| Name | Purpose | Set? |
|---|---|---|
| `PSI_KEY` | PageSpeed Insights API — CWV check degrades without it (429) | ❌ |
| `RESEND_KEY` | Lead notification email. **Without it no email sends at all.** | ❌ |
| `ADMIN_TOKEN` | Auth for `/admin/leads` and `/api/leads` | ❌ |
| `GITHUB_CLIENT_ID` / `_SECRET` | Decap CMS OAuth. Callback must be `https://svedsolution.com/api/callback` | ❌ |
| `SHEET_WEBHOOK_URL` | Overrides the hardcoded Apps Script URL | optional |
| `LEADS_KV` *(KV binding)* | Lead storage + rate limiting. Falls back to edge cache. | ❌ |

Redeploy after adding any variable — Functions read them at build time.

## Known open items

1. **Cloudflare Bot Fight Mode is blocking crawlers.** Ubersuggest recorded
   `business_type: "Unknown"` and auto-assigned IBM/Accenture as competitors
   because it never read the site. robots.txt is *not* the problem — all bot
   user-agents return 200; the block is a JS challenge to datacenter IPs.
   Fix: Security → Bots → off.
2. **Apps Script webhook returns 401** — deployment access must be `Anyone`.
3. **HSTS preload not submitted** — the single http→https hop is the last
   630ms on mobile. Submit at hstspreload.org.
4. No founder photograph, so `Person` schema has no image and the site's own
   audit flags it.
5. Use-case pages still use generic scenarios, not the real client stories.
