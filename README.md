# svedsolution.com

Site for **SVED Solution** — AI visibility & 360° SEO agency (GEO / AEO / LLM SEO).

Static site generated by a small Python build script, deployed on **Cloudflare Pages**,
with the audit tool, contact form and CMS auth running as **Pages Functions**.

## Stack

| Layer | Tech | Cost |
|---|---|---|
| Hosting | Cloudflare Pages | free |
| Build | Python 3 + `markdown` | free |
| Serverless | Pages Functions (`functions/`) | free, 100k req/day |
| Rate limit / cache | Workers KV | free |
| CMS | Decap CMS at `/admin/` | free |
| Forms | Resend | free, 3k/month |

## Layout

```
build.py              generator — page content lives here
assets/               style.css, app.js
content/blog/*.md     blog posts (edited via /admin/)
functions/api/        audit.js, contact.js, auth.js, callback.js
admin/                Decap CMS
static/               robots.txt, llms.txt, _headers, _redirects
dist/                 build output (gitignored)
```

## Local development

```bash
pip install -r requirements.txt
python build.py
python -m http.server 8787 --directory dist
```

Open http://localhost:8787

## Deploy

Every push to `main` triggers a Cloudflare Pages build.

| Setting | Value |
|---|---|
| Build command | `pip install -r requirements.txt && python build.py` |
| Output directory | `dist` |
| Root directory | *(blank)* |

Required environment variables: `PSI_KEY`, `RESEND_KEY`, `TO_EMAIL`,
`GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`.
Required KV binding: `AUDIT_KV`.

See [CLOUDFLARE-DEPLOY.md](CLOUDFLARE-DEPLOY.md) for the full setup guide.

## Writing content

Sign in at `https://svedsolution.com/admin/` with GitHub. Saving a post commits
markdown to `content/blog/`, which triggers a rebuild — live in about 60 seconds.
